File Purposes
=============

Documentation:
--------------
README.md          - Full installation guide, usage, troubleshooting
QUICKSTART.md      - Condensed instructions for quick setup
ARCHITECTURE.md    - Technical architecture and design details
FILES.txt          - This file listing

Configuration:
--------------
package.xml        - Defines package metadata and dependencies
setup.py           - Python package setup, entry points, data files
setup.cfg          - Installation directories configuration

Source Code:
------------
wheel_encoder_node.py - Converts joint states to wheel RPM
                      - Publishes wheel RPM
                      - Configurable publish rate

Launch Files:
-------------
gazebo_sim.launch.py - Starts Gazebo simulation
                     - Spawns car from URDF
                     - Starts robot_state_publisher
                     - Configurable world file

nodes.launch.py      - Starts sensor nodes
                     - Starts wheel encoder node
                     - Configurable parameters

Robot Model:
------------
car.urdf            - Defines car geometry (chassis + 4 wheels)
                    - Includes all sensor definitions
                    - Contains Gazebo plugin configurations
                    - Sensors: LiDAR, Camera, IMU, GPS, Wheel Encoders

World Files:
------------
test_world.world    - Simple test environment
                    - Ground plane + sun lighting
                    - 3 obstacle objects for sensor testing


Total Files Created: 14 files + 4 documentation files
Total Lines of Code: ~1400 lines
Primary Language: Python
